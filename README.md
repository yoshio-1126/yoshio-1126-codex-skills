FigmaのURLだけを送ると、対象の実データを読み取り専用で点検します。フレームのリンクや、Figma連携で渡した選択ノードも使えます。「この部分を整理して」と添えれば、その範囲を編集します。スキル名やモードの宣言は不要です。

個人版とデザイナー版を統合し、Pro版の詳細点検・整理・検証・引き継ぎを標準にしました。既存のリンクで引き続き使えるように、登録名は `figma-designer-pro` です。[スキル本文](.agents/skills/figma-designer-pro/SKILL.md)

### ルールを編集する

[Figmaデザイナースキルのスペース](https://chatgpt.com/space/page_6b07b7c0877481919dcb745aa76d020a) が制作ルールの正本です。点検基準・具体例・引き継ぎ手順はスペースで編集でき、次の作業時にCodexが読み直します。日々のルール変更にGitHubへのpushは不要です。自動発動の入口と整数寸法の検査コードはGitHubで更新します。別の利用者にも適用する場合は、各自のCodexでスペースの該当ページを読めるようにしてください。

### 使う環境に登録する

- **このリポジトリで作業する場合**　最新の `main` を作業環境に選んでチャットを開きます。ルートの [AGENTS.md](AGENTS.md) とリポジトリ内のスキルから適用されます。
- **別のプロジェクトでも使う場合**　このリポジトリの `.agents/skills/figma-designer-pro/` フォルダ一式を、作業先の `.agents/skills/` か、利用環境で有効な個人スキルのディレクトリに登録します。入口や検査コードを更新したときは登録先にも同期してください。旧 `figma-designer` を個別に導入している環境は、統合版に切り替えてから新しいチャットを開きます。
- **GitHub連携で読む場合**　作業先にスキルを設置できない場合は、次の一文を作業先の `AGENTS.md` に一度登録します。以降はFigmaデータを渡すだけで使えます。

> FigmaのURL・ファイル・選択ノードを受け取ったら、GitHub の yoshio-1126/yoshio-1126-codex-skills の main にある .agents/skills/figma-designer-pro/SKILL.md を取得し、そこからリンクされたChatGPT Spaceの最新の本文・必要な参照ページを読み、対象だけなら読み取り専用で点検してください。

実データの点検には、Figma連携と対象を閲覧できる権限が必要です。公開リポジトリをブラウザで開いただけでは、別の作業環境にスキルは登録されません。
