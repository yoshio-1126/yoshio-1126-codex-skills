# Codex スキル一覧

## Figmaデザイナースキル

Figmaのリンク・添付・選択中のフレームから実データを開き、相談の内容に応じて点検・整理・引き継ぎを行います。スキル名やモードの宣言は不要です。

個人版とデザイナー版を統合し、Pro版の詳細点検・整理・検証・引き継ぎを標準にしました。既存のリンクで引き続き使えるように、登録名は `figma-designer-pro` です。[スキル本文](.agents/skills/figma-designer-pro/SKILL.md)

2026年11月27日、初見検証後に確認ページの配置を更新し、 **v1** として確定しました。別のPCで同じ手順を使うときは、[v1のスキル一式](https://github.com/yoshio-1126/yoshio-1126-codex-skills/tree/v1/.agents/skills/figma-designer-pro)を参照してください。

### デザイナーからの依頼

初めて依頼するときは、このリポジトリとデザインを共有すれば、普段の言葉で作業を頼めます。初回は、構造の不備、配置に残る小数、同じルールから外れた箇所を短く列挙します。修正は独立したコピーに反映し、指摘資料には黒枠付きの原寸のオリジナルと説明を載せます。左から、枠線を足さないオリジナルと修正版をページ直下のフレームで並べ、その右に指示書とコンポーネントをそれぞれのセクションで置きます。オリジナルへの直接反映は、その希望を明示した場合に限ります。「まず報告だけ」と頼んだ場合はチャットで結果をお返しします。

スキル本文・参照資料・検査コードの正本はこのリポジトリの `main` です。FigmaデータとGitHubのスキルを読める環境で使えます。

### 使う環境に登録する

- **このリポジトリで作業する場合**　最新の `main` を作業環境に選んでチャットを開きます。ルートの [AGENTS.md](AGENTS.md) とリポジトリ内のスキルから適用されます。
- **別のプロジェクトでも使う場合**　このリポジトリの `.agents/skills/figma-designer-pro/` フォルダ一式を、作業先の `.agents/skills/` か、利用環境で有効な個人スキルのディレクトリに登録します。更新時は参照資料と検査スクリプトも含めて同期してください。旧 `figma-designer` を個別に導入している環境は、統合版に切り替えてから新しいチャットを開きます。
- **GitHub連携で読む場合**　作業先にスキルを設置できない場合は、次の一文を作業先の `AGENTS.md` に一度登録します。以降はFigmaデータを渡すだけで使えます。

> FigmaのURL・ファイル・選択ノードを受け取ったら、GitHub の yoshio-1126/yoshio-1126-codex-skills の main にある .agents/skills/figma-designer-pro/SKILL.md と必要な参照資料を読み、会話と対象から依頼の目的を判断して、該当する手順を適用してください。

実データの点検には、Figma連携と対象を閲覧できる権限が必要です。公開リポジトリをブラウザで開いただけでは、別の作業環境にスキルは登録されません。
