## クラウドチャットで使う

このリポジトリを作業環境に選んだら、「$figma-designer-pro で点検して」と対象のFigma URLを送ってください。

別案件のチャットでは、GitHub連携にこのリポジトリの閲覧権限を付けて、次の一文と対象のFigma URLを送ってください。

> GitHubの yoshio-1126/yoshio-1126-codex-skills にある .agents/skills/figma-designer-pro/SKILL.md と、そこから参照される資料を読んで、このフレームを個人版で点検してください。

Figmaの点検にはFigma連携とファイルの閲覧権限が必要です。「点検して」で読み取り、「ここを直して」で指定箇所を編集します。

## スキルを追加する

分野を問わず、スキルごとに `.agents/skills/<スキル名>/SKILL.md` を作り、上の一覧に一行追加します。補足資料は各スキルのフォルダにまとめ、相対リンクで参照します。
