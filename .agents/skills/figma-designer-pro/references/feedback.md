# 修正前と修正後の比較

比較資料には、編集前の対象フレーム全体と修正済みフレーム全体をネイティブ複製し、左・右に原寸で並べる。前後はそれぞれ実物の幅・高さ・子の順序・親子関係・表示・部品参照を維持する。全体を並べれば同じ画面を多数複製せずにすむ。比較用の切り取り、縮小、再組版、長文や移動を試した状態は掲載しない。

見出しと説明は両フレームの外に置く。対応するセクションの横に、確認できた全項目の「場所／何が問題だったか／何で解決したか」を短く添える。外観が同じ構造変更は操作で説明する（例「記事を動かすと写真が残る → 写真をカード内にまとめ、一緒に動く」）。

完成時は元・完成データとそれぞれの比較用複製の寸法、構造、表示を照合し、説明が画面に被っていないことを確認する。試験用コピーや別の保管版は検証ページに残さない。レビュー用に残す依頼ではページと成果物のIDを引き継ぎ、次の再検証を依頼された時に前回生成分を照合して片付け、同じ原本から開始する。
