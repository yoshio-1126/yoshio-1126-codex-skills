# 修正後にFigmaへ載せる実例

制作画面の外に「修正前／修正後」を並べる。左は編集前バックアップ、右は確認済みの作業結果から同じ箇所を同じ縮尺で抜き出す。修正の種類ごとに代表例を一組載せ、同じ原因の残りは件数でまとめる。承認待ち・未反映の案を完成例に含めない。

各組に「何が問題だったか」「何を変えて解決したか」を一行ずつ添える。間隔や小数なら該当する辺と実測値を示す。構造の修正で静止画の外観が同じなら、比較用の複製で前後に同じ移動や文言変更を行い、その結果を見せる。例えば「前：記事を動かすと写真が残る」「後：写真をカードに入れ、記事と一緒に動く」。

掲載後に読み戻し、前後のラベルと差が読み取れることを確かめる。Figmaに書き込めない場合は、未掲載であることと、確認できた修正前後を短く伝える。
