# 原本と注釈付き修正版

確認ページで比較する画面全体は2つ。左に「オリジナル」、右に「修正版」を原寸で上端をそろえて置く。別ページでは原本の複製を左に置き、入力元の構造・参照を保つ。必要な正本は独立したコンポーネント用セクションにまとめる。初回の読み取り点検はチャットに指摘を出して止める。承認後、修正版ができたらそこに注釈を書く。指示専用の画面複製や比較用の黒枠は作らない。

修正版の該当レイヤーを選ぶと、元の問題と今できることが短い1〜2文で読めるようにする。例「前は写真を移動すると説明が残りました。今はカードを選ぶと両方一緒に動きます」。未確定の文言は「要確認」と書き、対応済みの内容と区別する。

Plugin APIでは対象の `annotations` に `{label: "…"}` を保存する。既存注釈を保ち、同じ対応を重複させない。統合・削除されたものや注釈を置けない層は、修正版でその機能を引き継いだ最寄りの部品に付け、対象名を文中に入れる。原本と共用する正本は書き換えない。

完了前に比較ページの画面数、修正版内の注釈の対象ID・本文と承認項目、オリジナルの寸法・構造・参照を照合する。一時コピーを片付け、注釈付き修正版へ直接リンクする。旧形式の指示書を統合する場合は、必要な注釈を移し、件数と内容を読み戻してから旧指示書を片付ける。
