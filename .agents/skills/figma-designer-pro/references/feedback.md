# 実例で選べる初回提案

## 比較する範囲

- ばらつきは同じ役割・状態・基準幅の全件を同じ二辺で測る。各値の件数、外れた箇所、見た目が動く向きを記す。同型リンクの外側の列と、部品内の文字・アイコンの位置は別々に比較する。親の gap と実際の見える余白は一致しない場合がある。
- 文字は表示中の編集可能な範囲で書体・太さ・サイズ・行間・字間の違いを、色は実際の塗り・線・文字色と不透明度の違いを調べる。単発の例外と決める前に、別セクションの同じ役割に寄せたときの利点と失われる差を比べる。改行や描画差は実物で確認し、未測定の影響は見込みとして書く。
- 文字は実効書式数と参照スタイル数、色は単色RGBA数と参照変数数を別々に数える。対象、個別書式の層数、採用後の見込みを同じ母数で示す。複数案が重なるときは重複を除く。種類の削減数は採否の基準にしない。

## 見せ方

制作画面外の「指摘｜対象名」に、実物のネイティブ複製と比較対象を並べる。既存資料を更新するときは判断履歴を保つ。現状と案は同じ縮尺・周辺条件で表示し、小さな差にはガイドを添える。候補ごとに「対象・件数／実測した差／推奨と理由／表示または次の編集への影響／判断状態」を短く添え、元のノードへ辿れるようにする。理由のある個別仕上げは「このままでよい例」として示す。

値をそろえる例なら「4行中3行は見出しの下が16 px、この行だけ24 pxです。16 pxにすると本文が8 px上がります」。意図が割れる例なら「この見出しは他の章と同じ役割にも、カード専用の小見出しにも見えます。次に章見出しを大きくしたら、ここも変えたいですか？」。実際の提案では対象の名前・値に置き換え、選択が不要な項目まで質問にしない。

最初に判断したい代表例を置き、同じ原因の全件・越境した辺と量・小数の内訳はその下にまとめる。字形が収まる文字枠の越境も追跡できるようにする。文字見本と色チップを並べ、反映後は同じ比較に実測値と状態を追記する。比較用の複製・見本は実使用数から外す。返答前に資料を読み戻し、比較が見えること、見た目が変わる全案がチャットと対応することを確かめる。読み取り依頼では実物のノードリンクと並列表で同じ判断材料を渡す。
