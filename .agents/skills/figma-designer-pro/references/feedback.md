# 原本と注釈付き修正版

確認ページで比較する画面全体は2つ。左に「オリジナル」、右に「修正版」を原寸で上端をそろえて置く。別ページでは原本の複製を左に置き、入力元の構造・参照を保つ。必要な正本は独立したコンポーネント用セクションにまとめる。初回の読み取り点検はチャットに指摘を出して止める。承認後、修正版ができたらそこに注釈を書く。指示専用の画面複製や比較用の黒枠は作らない。

注釈を付けるのは次の2種類だけ。該当がなければ0件でよい。
- **要確認**　正式原稿・写真・表記・見た目の意図など、デザイナーに決めてほしい内容。「右の記事タイトルは仮原稿です。掲載するタイトルを確認してください」。
- **調整しました**　実際に変えた見た目。「オンライン会議だけ図と名前が離れていたので、他の工程と同じ間隔にそろえました」。原本と修正版の表示を比較してから書く。対象と見える差が伝われば十分。

フレームの組み替え、部品化、一括選択、幅変更での折り返し、後続の追従、試験した幅・件数は作業検証として扱い、Figmaの注釈には載せない。内部作業と見た目の調整を一緒に行ったときも、注釈には見える差だけを書く。デザイナーが確認する必要のある原稿・写真は、推測で確定しない。

Plugin APIでは対象の `annotations` に `{label: "…"}` を保存する。デザイナーが書いた既存注釈を保ち、同じ対応を重複させない。以前の自分の成果物を更新する場合は、作業報告だけの自分の注釈を外す。統合・削除されたものや注釈を置けない層は、修正版でその機能を引き継いだ最寄りの部品に付け、対象名を文中に入れる。原本と共用する正本は書き換えない。

完了前に比較ページの画面数、修正版内の注釈の対象ID・本文と、実際の見た目の差・未決事項の対応、オリジナルの寸法・構造・参照を照合する。一時コピーを片付け、注釈付き修正版へ直接リンクする。旧形式の指示書を統合する場合は、必要な注釈を移し、件数と内容を読み戻してから旧指示書を片付ける。
