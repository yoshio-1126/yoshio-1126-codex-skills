# オリジナル＋指摘

検証ページ直下に、左から「オリジナル」「修正版」「オリジナル＋修正指示書」「コンポーネント」を上端をそろえて横一列に置く。各セクションの右端から間隔を取って次を配置する。左端は原本全体の原寸・ネイティブ複製、二番目は実際に編集する画面、三番目は原本全体の別の原寸複製とその横の指摘、右端は修正版が使う必要な正本だけ。入力元のページと正本は移動しない。両方の原寸複製は原本の構造と参照を保つ。白地の端も見えるよう、原寸複製の外周に黒の細い実線を置く。線は資料上の別要素とし、原本・制作画面・複製の寸法や内部構造は変えない。

指摘は該当エリアの横に置き、画面に重ねない。項目ごとに「場所／どこが不揃いか、何が困るか」を短く書く。反映後は実際にそろえたルールや修正内容をひと言添える。共通カードなら、例えば「写真と本文の上下位置が不揃い → 全カードで中央揃え」。修正結果の全画面は修正データへリンクする。

原本との寸法・構造の一致、黒枠の四辺、注記の読みやすさを確認する。確認用に残すページと成果物のIDを引き継ぎ、次の再検証を依頼された時に前回生成分だけを片付け、同じ原本から始める。
