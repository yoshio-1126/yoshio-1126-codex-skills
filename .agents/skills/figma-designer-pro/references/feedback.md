# オリジナル＋指摘

検証ページには「修正データ」「指摘資料」と、使用する正本があるときは「共有パーツ」を同階層の独立したセクションに置く。指摘資料に載せる画面は編集前の対象フレーム全体を原寸・元の構造で複製した一枚だけ。白地の端も見えるよう、その外周に黒の細い実線を置く。線は資料上の別要素とし、原本・制作画面・複製の寸法や内部構造は変えない。

指摘は該当エリアの横に置き、画面に重ねない。項目ごとに「場所／どこが不揃いか、何が困るか」を短く書く。反映後は実際にそろえたルールや修正内容をひと言添える。共通カードなら、例えば「写真と本文の上下位置が不揃い → 全カードで中央揃え」。修正結果の全画面は修正データへリンクする。

原本との寸法・構造の一致、黒枠の四辺、注記の読みやすさを確認する。確認用に残すページと成果物のIDを引き継ぎ、次の再検証を依頼された時に前回生成分だけを片付け、同じ原本から始める。
