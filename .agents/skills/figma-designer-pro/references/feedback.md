# オリジナル＋指摘

検証ページでは次の順に上端をそろえ、間隔を空けて横に並べる。

1. **オリジナル**　原本全体の原寸複製をページ直下のフレームにする。
2. **修正版**　編集した画面全体をページ直下のフレームにする。1・2はセクションで囲わず、比較用の線も足さない。
3. **オリジナル＋修正指示書**　原本全体の別の原寸複製を一つのセクションに入れ、指摘対象のレイヤーにネイティブのアノテーションを付ける。この複製の外周だけに、同寸・塗りなし・黒の細い実線の長方形を重ねる。
4. **コンポーネント**　修正版が使う正本を独立したセクションにまとめる。

入力元は元の場所に保ち、原寸複製は原本の構造と参照を引き継ぐ。

指示を読む人が、該当箇所を選べば次の操作をイメージできる文にする。一件につき短い1〜2文。「この写真だけ、説明を動かすと取り残されます。修正版では写真と説明を一緒に動かせます」「この工程名だけ図から離れていました。他の工程と同じ間隔にそろえました」のように、画面上の名前と動作を書く。設定用語や番号だけの指摘、独立した説明テキスト・付箋・コメントによる代用は避ける。

Plugin APIでは該当ノードの `annotations` に `{label: "…"}` を設定する。既存の注釈を保持し、自分が追加した指示は重複させない。対象が注釈に対応しなければ、指示書の複製内でその部分を含む最寄りの対応フレームに付け、対象を文中で特定する。完了前に承認項目と注釈の対応、対象ID・本文を再取得して照合する。生成環境で保存できない場合は未作成の項目を明示する。

原本との寸法・構造の一致、黒枠の四辺、注記の読みやすさを確認する。確認用に残すページと成果物のIDを引き継ぎ、次の再検証を依頼された時に前回生成分だけを片付け、同じ原本から始める。
