# デザイナー用Figmaスキル（個人版）

クラウドチャットでの使い方は[スキル一覧](../../../README.md)を参照してください。

ZIPをローカル作業ができるCodexのチャットに添付し、「このZIPの figma-designer-pro を、今後のチャットでも使える個人スキルとしてインストールして」と送ってください。環境が書き込みの許可を求めたら、保存先を確認してください。

新しいチャットで **「個人版でデザインを始めます」＋ FigmaのURL** と送ると、その範囲を読み取り専用で点検します。明示的に選ぶ場合は `$figma-designer-pro` でも呼び出せます。Figmaへの接続と対象ファイルの閲覧権限は利用者の環境で必要です。

「ここを直して」は指定範囲の修正、「納品用に整理して」は点検と引き継ぎ資料の作成です。同梱ファイルだけで利用できます。
